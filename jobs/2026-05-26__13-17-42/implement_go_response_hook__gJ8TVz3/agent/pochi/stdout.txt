### How the hook works

```go
// inject_header_hook.go
func (h *InjectHeaderHook) AfterSuccess(_ HookContext, res *http.Response) (*http.Response, error) {
    if res.Header == nil {
        res.Header = make(http.Header)
    }
    res.Header.Set("X-Hook-Injected", "true")
    return res, nil
}
```

- Satisfies the `AfterSuccessHook` interface.
- Defensively initialises the header map if nil.
- Uses `http.Header.Set` (canonical key form) so the header is accessible as `res.Header.Get("X-Hook-Injected")` → `"true"`.
- Registered in `registration.go` so the `Hooks` dispatcher calls it for every successful response.
